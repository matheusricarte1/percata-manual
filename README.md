# PERCATA — Caderno de Fluxos

Versão pública e estática do manual de uso do PERCATA.

O site é publicado por GitHub Pages. As imagens são capturas anonimizadas do sistema e acompanham o manual para que a navegação e as demonstrações funcionem sem dependências externas.

## Atualização

1. Gere o manual a partir do diretório principal do projeto.
2. Atualize `index.html` e as imagens PNG desta pasta.
3. Publique a alteração na branch `main`.
